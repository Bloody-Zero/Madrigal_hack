## Автоматические тесты

1. Одинаковый поток и 3 сообщения из PCAP и PCAPNG.
2. Изменённый порядок и одинаковая повторная передача без дублирования байтов.
3. Пропуск не превращается в нулевое значение поля.
4. Конфликтное перекрытие не интерпретируется.
5. Усечение последнего байта диагностируется.
6. Переход sequence number через 2^32.
7. Повторное использование той же четвёрки адресов/портов остаётся другой сессией.
8. Захват без начала не устанавливает роли и начало.
9. Ссылки на пакеты воспроизводят точные байты выбранного диапазона.
10. Дополнительная запись: новое значение 300 и сообщение переменной длины 265 байт.
11. Ошибочное правило находит контрпример; исправление меняет результат.
12. Неописанные области остаются видимыми.
13. Некорректные правила отклоняются.
14. Отменённый импорт не публикует источник.
15. Дедупликация, устаревание проверки, перенос проекта и повторный результат.
16. Изменение исходного файла обнаруживается.
17. Ошибка checksum не удаляет пакет.
18. API требует токен для записи и отвергает внешний Host.
19. Второй процесс не может одновременно открыть проект для записи.
20. Сообщение с пустым телом корректно разбирается.
21. Отсутствующий хвост перед видимым FIN отмечается пропуском.

## Браузерный сценарий

Загрузка training.pcap и additional.pcap → выбор корпуса → 5 разобранных сообщений →
переход от поля к байтам → сохранение гипотезы → импорт 4 действий CSV → ближайший
обмен по времени → изменение ширины длины на 1 → нарушения → возврат ширины 2 →
HEX-поиск → сравнение диапазонов → перезагрузка страницы с сохранёнными данными.

Оформление экрана просмотра проверено визуально. Скриншоты проверки не входят в комплект.
