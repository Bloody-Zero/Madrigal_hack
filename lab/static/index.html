Первое исследование
  1. Импортируйте examples/training.pcap и additional.pcap.
  2. В разделе «Журнал» загрузите actions.csv.
  3. Выберите поток с данными. Посмотрите HEX и исходные пакеты.
  4. В «Правилах» оставьте профиль AA55 + тип + длина тела. Добавьте поле value: offset 5, uint16, big.
  5. Выберите галочками потоки с данными и проверьте корпус.
  6. Для контрпримера смените ширину поля длины с 2 на 1: короткие и длинные сообщения перестанут соответствовать описанию. Верните правило и повторите проверку.
  7. Выделите байты, сохраните гипотезу с основаниями.
  8. Скачайте HTML-отчёт, JSON правил и ZIP проекта. Распакуйте проект в другую папку и откройте лаунчером.
Файлы examples — синтетические пакетные фикстуры. Они проверяют код, но не заменяют исследование корпуса организаторов.
Неизвестный хвост при недоступном поле длины не угадывается. Автоматической ресинхронизации по маркеру в 0.1 нет.
Приложение работает на localhost. Закрытие вкладки не останавливает сервер; остановка — Ctrl+C в терминале.
